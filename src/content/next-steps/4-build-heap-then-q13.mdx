Half of this ran early: <b>the heap was built on 9 Sep</b>, not the 11th, because the re-pass it was displaced by took thirty minutes and left the block open. <a href="/internals#17-heaps">Section 17</a> covers it — one rule, array-backed because the tree is complete, and <code>siftDown</code> framed as <em>find the smallest among three</em>. What remains is the half it was built for. <a href="/coding/13">Top K Frequent</a> has been solved by sorting since 25 Aug — the <code>O(m log m)</code> answer the follow-up exists to rule out — and <b>the only reason it stood that long was that there was no heap to replace the sort with.</b> There is now. Take the two-minute measurement with it: a comparison counter at n = 100,000, which is <a href="/open#heap-tests-that-a-linear-scan-would-also-pass">the only thing that can distinguish the heap from a linear scan</a>, since every correctness test passes against both.
