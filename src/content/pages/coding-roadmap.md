Arrow keys step the trace, space plays it. The morning Apple block runs <b>one problem per session, timeboxed to 25 minutes with the timer started before reading</b> — the two-problem target was <a href="/open#two-problems-at-ninety-minutes">retired on 1 Sep</a> because throughput was never the bottleneck. The evening DSA course keeps its own 15-per-topic structure. Roadmap: <b>arrays &amp; strings</b> → two pointers → sliding window → hash maps → linked lists → stacks &amp; monotonic stack → recursion → binary search → trees → heaps → graphs → backtracking → sorting → greedy. Everything through hash maps is <a href="/open#coverage-every-problem-inside-topic-1">where all the problems so far sit</a>; linked lists onward is the <a href="/plan">phase 2 breadth track</a> from 14 Sep, with DP on its Saturdays.
