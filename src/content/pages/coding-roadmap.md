title: Coding roadmap
---

Arrow keys step the trace, space plays it. The morning Apple block runs <b>two easy-to-medium problems per session</b> per the calendar; the evening DSA course keeps its own 15-per-topic structure. Roadmap: <b>arrays &amp; strings</b> → two pointers → sliding window → hash maps → linked lists → stacks &amp; queues → recursion → binary search → trees → heaps → graphs → DP → sorting → greedy.
